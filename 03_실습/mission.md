**미션 1 — 주석으로 HTML 만들기**

빈 `index.html` 을 만들고 주석 한 줄을 치세요.

`<!-- 계좌번호, 잔액, 상태가 보이는 은행 계좌 카드 한 장 -->`

자동완성이 뭐라고 하는지 보고, `Tab` 으로 받아보세요.

**미션 2 — `Ctrl+I` 로 CSS 붙이기**

방금 만든 HTML을 **전체 선택**하고 `Ctrl+I` 로 요청하세요.

> "이 카드에 어울리는 CSS를 만들어줘. 흰 배경에 모서리 둥글게, 그림자 살짝. 모바일에서 보기 좋게."
>

**미션 3 — Live Server로 띄우기**

`index.html` 에 우클릭 → **Open with Live Server**. 브라우저가 열립니다.

CSS를 고치고 저장하면 **새로고침 없이** 바뀝니다. 한 번씩 직접 해보게 하세요.

**미션 4 — 거절해보기**

자동완성 제안을 일부러 **`Esc` 로 거절**해보세요.
